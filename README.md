# StockMarketAnalysis
# Stock Market Analysis using Python

## Overview

This project performs basic stock market analysis using Python. Historical stock data is downloaded using Yahoo Finance and analyzed using moving averages and daily returns.

## Features

* Download historical stock data
* Visualize stock price trends
* Calculate 20-Day Moving Average (MA20)
* Calculate 50-Day Moving Average (MA50)
* Generate Buy/Sell Signals
* Calculate Daily Returns
* Display basic stock statistics

## Technologies Used

* Python
* Pandas
* Matplotlib
* yFinance

## Sample Analysis

The project analyzes Reliance Industries stock data from 2024 and visualizes price movements along with moving averages.
